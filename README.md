# Operation: Make Her Smile 🎂
## Run (VS Code)
1. Install the **Live Server** extension, open this folder, right-click `index.html` → *Open with Live Server*. (Or run `python -m http.server` and open localhost:8000.)
## Add your files
- Childhood photos → `assets/images/childhood-1.jpg … 3`
- Memory photos → `assets/images/memory-1.jpg … 6` (fewer is fine; missing ones are hidden)
- Background music → `assets/audio/website-background.mp3`
- Final video (Dheema Dheema) → `assets/video/birthday-final.mp4` (use H.264/AAC MP4)
## Customize
Everything personal (name, captions, your message, file paths) is in the `birthdayConfig` object at the top of `js/main.js`.
Jokes/quiz text: `js/interactions.js`. Colours: top of `css/style.css`.
